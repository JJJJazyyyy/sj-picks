개인정보처리방침 — 주식 한끼 업로더

시행일: 2026년 11월 6일

1. 이 도구는 무엇인가요

'주식 한끼 업로더'는 유튜브 채널 '주식 한끼' 운영자 한 사람이 본인 채널에 영상을 예약 업로드하려고 쓰는 개인용 프로그램입니다. 일반 사용자에게 제공하지 않습니다.

2. 사용하는 정보

Google 계정 로그인으로 YouTube Data API 권한(영상 업로드, 본인 채널 읽기)을 받아 운영자 본인 채널에 영상을 올리고, 제목·설명·썸네일·공개 예약 시간을 설정합니다. 그 밖의 개인정보는 수집하지 않습니다.

3. 보관과 공유

로그인 결과(인증 토큰)는 운영자 PC 안에만 저장되며 외부 서버로 보내거나 제3자와 공유하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

5. 권한 철회

Google 계정의 '타사 앱 및 서비스' 설정에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다.
